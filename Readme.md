# Vanilla JS Machine Coding

Frontend machine-coding practice in plain HTML, CSS and JavaScript (no frameworks), built Aug–Sep 2026 while preparing for frontend interviews. Each folder is a standalone problem: open its `index.html` in a browser.

| Problem | Highlights |
|---|---|
| Pagination | Prev/next, page numbers, jump to page, search, category filter |
| Infinite Scroll | Load on scroll, loading and empty states, debounced search, category filter |
| Image Carousel | Slide navigation |
| Modal | Open/close behaviour |
| Accordion | Expand/collapse sections |
| Nested Accordion | Accordion inside accordion |
| Tabs | Switchable tab panels |
| Search Filter | Live filtering of a list |
| Todo | Add, complete and delete tasks |
| Notes App | Create and manage notes |
| Expense Tracker | Track and total expenses |
| Theme Switcher | Light/dark theme toggle |
| Color Palette | Color generation |
| Counter | Increment/decrement |

Concepts practised: DOM manipulation, event handling and delegation, debouncing, pagination logic, state kept in plain JavaScript, localStorage.
